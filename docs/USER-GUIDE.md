# Dunco HMS — User Guide

## Getting Started

### Login

1. Navigate to https://hmse.duncowebsolutions.co.ke/login
2. Enter your email and password
3. Click "Login"

### Dashboard

After login, you will see the main dashboard with:
- Hospital overview statistics
- Today's appointments
- Revenue summary
- Patient count
- Recent activity

## Core Modules

### Patient Registration

1. Navigate to **Patients** in the sidebar
2. Click **Add Patient**
3. Fill in required fields (name, date of birth, gender, phone, email)
4. Add emergency contact information
5. Add insurance information (if applicable)
6. Click **Save**

### Appointment Booking

1. Navigate to **Appointments** in the sidebar
2. Click **Book Appointment**
3. Select patient
4. Select doctor
5. Choose date and time
6. Add notes
7. Click **Save**

### Queue Management

1. Navigate to **Queue Management**
2. Generate token for patient
3. Call token when ready
4. Start service
5. Complete or cancel as needed

### Clinical Consultation

1. Open patient record
2. Record vital signs
3. Review medical history
4. Perform clinical examination
5. Record diagnosis (with ICD-10 code)
6. Issue prescriptions
7. Order lab tests (if needed)
8. Schedule follow-up

### Prescriptions

1. Navigate to **Pharmacy → Prescriptions**
2. Create new prescription
3. Select patient
4. Add medicine items with dosage
5. Save prescription

### Laboratory

1. Navigate to **Laboratory**
2. Create lab request
3. Select tests from catalog
4. Assign technician
5. Record results
6. Approve and print report

### Billing

1. Navigate to **Billing → Invoices**
2. Create invoice
3. Add line items (consultations, procedures, medicines, tests)
4. Apply discounts (if applicable)
5. Generate invoice
6. Process payment (cash, M-Pesa)

### Insurance Claims

1. Navigate to **Insurance → Claims**
2. Create new claim
3. Link to patient insurance
4. Add diagnosis and service codes
5. Set claimed amount
6. Submit claim

## Patient Portal

### Access

1. Navigate to the Patient Portal login
2. Enter patient credentials
3. Complete 2FA verification (if enabled)

### Available Features

- View appointments
- View prescriptions
- View lab results
- View medical history
- View billing information
- Update profile

## Reports

1. Navigate to **Reports** in the sidebar
2. Select report type
3. Set filters (date range, department, etc.)
4. Generate report
5. Export as PDF or Excel

## Settings

1. Navigate to **Settings** in the sidebar
2. Update hospital information
3. Manage branches
4. View audit logs
5. Backup/restore data
