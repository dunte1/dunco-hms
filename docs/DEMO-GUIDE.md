# Dunco HMS — Demo Guide

## Demo URL

**https://hmse.duncowebsolutions.co.ke/**

## Demo Credentials

Demo credentials should be provisioned separately for prospective clients.

**Important:** Do not use production administrator credentials for demonstrations. Create dedicated demo accounts with limited data.

### Recommended Demo Setup

1. Create a demo user account (e.g., demo@duncowebsolutions.co.ke)
2. Assign appropriate role (e.g., Hospital Admin)
3. Seed demo patient data
4. Seed demo appointments and records
5. Reset demo data periodically

## What to Demonstrate

### 1. Login & Dashboard
- Show the login page
- Demonstrate role-based dashboard
- Show real-time statistics

### 2. Patient Registration
- Register a new patient
- Show auto-generated patient number
- Demonstrate search functionality

### 3. Appointment Booking
- Book an appointment
- Show queue management
- Demonstrate token generation

### 4. Clinical Workflow
- Open patient record
- Record vital signs
- Create diagnosis with ICD-10
- Issue prescription
- Order lab tests

### 5. Pharmacy
- View medicine catalog
- Process prescription
- Show stock management

### 6. Laboratory
- Create lab request
- Record test results
- Generate lab report

### 7. Billing
- Generate invoice
- Process payment (show M-Pesa option)
- Generate receipt

### 8. Insurance/SHA
- Show SHA member verification
- Demonstrate claims workflow
- Show pre-authorization

### 9. Reports
- Generate patient report
- Show revenue report
- Demonstrate export to PDF/Excel

### 10. Administration
- Show user management
- Demonstrate role/permission system
- Show audit logs
- Show settings

## Notes

- System contains minimal production data (1 user, 1 patient)
- Most modules have empty data tables
- Focus on UI/UX and workflow demonstration
- Show the breadth of features available
